Этот проект содержит переведённые на русский язык книги по Фазе Затмения.

Перевод на русский язык осуществляется с помощью LLM и в дальнейшем вычитывается.

В мои задачи входит как можно скорее получить готовый материал, поэтому вычитка второстепенна. Если есть замечания или предложения о помощи, прошу писать на почту kasatkin.vit@gmail.com

Официальный сайт издателя книг: https://eclipsephase.com/
